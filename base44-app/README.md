# Base44-udgave

Koden i denne mappe er hjemmesiden flyttet fra Next.js til Base44's TanStack Start-skabelon
(app "Knud Pedersen" i Base44). Siderne i `src/views` er de samme som i `src/app`, men oversat til JavaScript;
`src/routes` er TanStack-ruterne, og `src/lib/next` er små erstatninger for next/link og next/navigation.
Formularerne gemmer henvendelser i Base44 (entiteterne Henvendelse og Nyhedsbrev).
